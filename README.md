# 🎮 FTXUI-2048 Game

一款基于 **FTXUI** 现代 C++ 终端 UI 库开发的经典 **2048 终端版游戏**。项目采用 C++11/14 标准编写，使用 CMake 进行构建，支持跨平台编译与运行。

界面精美、响应流畅，专为热爱终端极简风格与经典益智游戏的开发者打造。

---

## ✨ 项目亮点

- **现代终端 UI**：基于著名的 `ArthurSonzogni/FTXUI` 库构建，告别传统死板的控制台，拥有丝滑的局部刷新和高颜值色彩搭配。
- **四向矩阵旋转算法**：核心移动逻辑采用优雅的矩阵旋转复用机制，用最精简的代码实现了完美无 Bug 的四向碰撞与合并。
- **分值实时统计**：不仅能畅快移动，还能实时计算每次合并得分。
- **现代化构建工具链**：完整支持 CMake 构建，完美适配 Visual Studio、GCC 及 Clang 编译器。

---

## 🛠 开发环境与依赖

在编译运行本项目前，请确保您的系统已安装以下工具：

## 🎮 游戏具体玩法

- **🕹 操作说明**： 游戏启动后会展现 4x4 的蓝色精致棋盘，你可以通过以下按键控制盘面：W / ↑ ：向上滑动A / ← ：向左滑动S / ↓ ：向下滑动D / → ：向右滑动Q ：退出游戏
- **📋 核心规则**： 每次按下方向键，盘面上所有的数字方块都会齐刷刷地向该方向靠拢。
两个数值相同的方块撞在一起时，会融合成一个它们相加之和的新方块。
每有效移动一次，空白格子会随机诞生一个新的 2 或 4。
终极目标：在 4x4 的格子里，通过运筹帷幄拼出终极方块 —— 2048！当格子被填满且四周相邻格子均无法合并时，游戏结束。

## 🚀 编译与运行指南

### 方法一：使用 Visual Studio (推荐 👍)

1. 启动 **Visual Studio**，选择 **“打开本地文件夹”**。
2. 选中本项目的根目录文件夹（即包含 `CMakeLists.txt` 的文件夹）。
3. VS 会自动激活 CMake 并在底部输出“CMake 生成完毕”。
4. 点击顶部工具栏的 🟢 **“绿色小三角（启动按钮）”**（或直接按 `F5`），即可自动编译并拉起游戏。

### 方法二：使用命令行 (Git Bash / Terminal)

如果你更喜欢在终端中完成一切，请在项目根目录下依次执行以下命令：

```bash
# 1. 创建并进入构建目录
mkdir build && cd build

# 2. 使用 CMake 配置项目
cmake ..

# 3. 编译生成可执行文件
cmake --build .

# 4. 运行游戏
./FTXUI-Game   # Windows 下为 .\Debug\FTXUI-Game.exe 或直接在 out 目录下查找
